Лабораторная работа №5
Улучшаем лабораторную работу 3. Здесь уже учимся манипулировать DOM деревом, находить элементы, изменять содержимое и стили, а также сохранять состояние страницы между перезагрузками через localStorage.
 
Было реализовано:
1. Поиск элементов через getElementById (кнопки, список, секция), querySelector (текст внутри li) и querySelectorAll (все li при сохранении и очистке).
2. Создание новых li через createElement, добавление текста через createTextNode и span, вставка через appendChild, удаление через remove(), изменение классов через classList.
3. Переключение темы: со светлой на темную и наоборот.
4. Скрытие/показ списка навыков.
5. Обработка ошибок (проверка элемента, всех кнопок).
6. Сохранение навыков, выбранной темы и состояния скрытия списка.
